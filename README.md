# TODO on 📝

친구들끼리 쓰는 가벼운 할 일 관리 앱이에요. Windows 데스크톱과 Android에서 Firebase로 실시간 동기화됩니다.

## 다운로드

[Releases](../../releases/latest) 페이지에서 최신 Windows 버전을 받을 수 있어요.

1. `TODOon-windows-*.zip` 다운로드
2. 압축 해제 (폴더째로 유지)
3. `todo_mate.exe` 실행

## 주요 기능

- 카테고리별 할 일 관리, 드래그로 순서 변경/카테고리 이동
- 캘린더에서 날짜별 할 일 미리보기, 공휴일 표시
- 날짜별 일기(비공개)
- 친구 코드로 연결해서 서로의 프로필과 오늘 할 일 보기 (비공개 카테고리는 제외)
- 라이트/다크 테마

## 개발 스택

Flutter + Riverpod + Firebase (Auth, Firestore)
